# Классификатор обращений — Команда Prompt & Pray

Автономный сервис для экспресс-классификации входящих обращений по трём категориям (**справка**, **жалоба**, **другое**) и автоматической генерации вежливых черновиков ответов на русском языке.

---

## 1. Что реализовано
- **Консольный скрипт (`classify.py`)**: читает обращения из файла [`messages.txt`](messages.txt), распознаёт категорию и формирует готовый к отправке черновик ответа.
- **Интерактивное веб-демо (`index.html`)**: клиентское приложение (Single Page Application), работающее прямо в браузере без необходимости запуска сервера или API-ключей. Поддерживает как разбор одиночных сообщений, так и пакетный режим.
- **Модульные тесты (`test_classifier.py`, `test_web.js`)**: полный набор проверок соответствия ТЗ, устойчивости к ошибкам и синхронизации логики Python и JavaScript.

---

## 2. Как устроено решение
1. **Нормализация входных данных (`clean_text`)**:
   - Очистка от лидирующих номеров и спецсимволов (`1)`, `2.` и т.п.).
   - Приведение вариантов дефисов и тире к стандарту (включая неразрывный дефис `\u2011` в «Wi‑Fi»).
   - Схлопывание повторяющихся пробелов и нормализация регистра.
2. **Анализ интента и приоритизация**:
   - **Жалоба** имеет наивысший приоритет: если в обращении присутствуют маркеры проблемы («не выдают», «холодная», «сломал»), оно классифицируется как жалоба, даже при упоминании справки.
   - **Справка**: выявляются запросы документов, выписок и подтверждений обучения.
   - **Другое**: организационные вопросы, запись на консультации, навигация и гостевая парковка.
3. **Генерация черновика ответа**:
   - Черновик формируется в деловом тоне («Здравствуйте!»), запрашивает недостающие уточняющие детали (номер корпуса, дата, блюдо, специалист) и не даёт ложных обещаний автоматической регистрации.

---

## 3. Технологии и данные
- **Язык**: Python 3.8+ (только стандартная библиотека: `re`, `sys`, `pathlib`, `typing`, `unittest`).
- **Зависимости**: отсутствуют (0 внешних библиотек), см. [`requirements.txt`](requirements.txt).
- **Веб-интерфейс**: чистый HTML5 / Vanilla JS / CSS (Tailwind CSS через CDN).
- **Входные данные**: [`messages.txt`](messages.txt) (5 исходных обращений в кодировке UTF-8).

---

## 4. Установка и запуск

Проект готов к запуску в чистом окружении без предварительной настройки:

```bash
# 1. Запуск защищенного веб-сервера (рекомендуется):
# Сервер берет ваш GEMINI_API_KEY из .env и скрывает его от пользователей сайта.
python3 server.py

# 2. Основной консольный запуск (быстрый оффлайн-режим на правилах):
python3 classify.py

# 3. Консольный запуск с Google Gemini API:
python3 classify.py --llm

# 4. Запуск автоматических тестов
python3 -m unittest -v test_classifier.py
```

*Для запуска интерактивного веб-демо достаточно открыть файл `index.html` в любом современном браузере.*

## 5. Проверка основного сценария (Результаты работы)

При выполнении команды `python3 classify.py` скрипт обрабатывает все 5 контрольных обращений:

| № | Входное обращение | Категория | Черновик ответа |
|:---:|:---|:---:|:---|
| **1** | *Как получить справку о месте учёбы?* | **справка** | Здравствуйте! Для получения справки о месте учёбы уточните в учебной части вашего учреждения порядок оформления и срок выдачи. Сообщите, пожалуйста, для какой организации нужна справка. |
| **2** | *В столовой очередь, еда холодная.* | **жалоба** | Здравствуйте! Спасибо, что сообщили о ситуации в столовой. Укажите, пожалуйста, дату и время посещения, а также блюдо или кассу. Эти сведения помогут ответственным сотрудникам проверить обращение. |
| **3** | *Хочу записаться на консультацию завтра.* | **другое** | Здравствуйте! Уточните, пожалуйста, к какому преподавателю или специалисту вы хотите записаться и какое время вам удобно. Это поможет подсказать порядок записи на консультацию. |
| **4** | *Пропал Wi‑Fi в корпусе B.* | **жалоба** | Здравствуйте! Спасибо за сообщение о проблеме с Wi-Fi. Укажите корпус, место и примерное время сбоя, а также устройство, на котором пропала связь. Это поможет проверить соединение. |
| **5** | *Где парковка для гостей?* | **другое** | Здравствуйте! Уточните, пожалуйста, в какой корпус вы направляетесь и когда планируете приехать. Это поможет сообщить актуальные условия въезда и расположение гостевой парковки. |

## 6. Базовая надёжность и обработка исключений
- **Устойчивость к некорректным файлам**: при отсутствии файла, пустом файле или неверной кодировке скрипт выводит понятное сообщение об ошибке в `stderr` с кодом возврата `1` без вызова необработанных исключений (Traceback).
- **Кроссплатформенность**: скрипт корректно настраивает потоки ввода-вывода UTF-8 для работы в консолях Windows (cp1251), Linux и macOS.
- **Безопасность**: веб-интерфейс экранирует пользовательский ввод для предотвращения XSS-инъекций.

## 7. Гибридная архитектура и потенциал развития
- **Гибридный подход (Zero-dependency Core + LLM Provider)**: по умолчанию скрипт работает на сверхбыстрых детерминированных правилах (0 мс задержки, 0 внешних пакетов, не требует интернета и ключей). При передаче флага `--llm` скрипт подключает бесплатный Gemini 1.5 Flash API через стандартную библиотеку Python (`urllib.request`).
- **Безотказность (Fail-safe Fallback)**: если при вызове LLM отсутствует ключ, превышен лимит или пропал интернет, сервис автоматически и без падения переключается на локальные правила.
- **Потенциал масштабирования**: решение готово к встраиванию в Telegram-боты, интеграции с CRM-системами вузов или развёртыванию в качестве микросервиса.
