# Классификатор обращений — Prompt & Pray

Решение репетиционного кейса: скрипт читает пять строк из `messages.txt` и печатает для каждой категорию (**справка / жалоба / другое**) и один черновик ответа на русском. Категории определяются правилами по тексту, черновик выбирается по теме. LLM и внешние сервисы не используются.

## Запуск и проверка

Нужен Python 3.10 или новее; сторонних Python-пакетов нет. Из каталога репозитория:

```bash
python classify.py
python -B -m unittest -v test_classifier.py
```

На системах, где команда Python называется `python3`, замените `python` на `python3`. Скрипт можно запустить из другого каталога по абсолютному пути. По умолчанию он найдёт `messages.txt` рядом с собой; свой UTF-8 файл с одним обращением на строку передаётся как `python classify.py путь-к-файлу`. Пустые строки пропускаются. Пустой, отсутствующий или не-UTF-8 файл вызывает понятное сообщение об ошибке.

| № | Тема обращения | Категория |
|---|---|---|
| 1 | Справка о месте учёбы | справка |
| 2 | Очередь и холодная еда | жалоба |
| 3 | Запись на консультацию | другое |
| 4 | Пропал Wi-Fi | жалоба |
| 5 | Гостевая парковка | другое |

Дополнительное локальное демо — `index.html`: откройте файл в браузере, введите обращение или нажмите «Несколько сразу» → «Загрузить 5 из задания» → «Разобрать все». Браузер выполняет ту же логику на JavaScript без сервера и API-ключа. При наличии Node.js совпадение результатов двух реализаций проверяется командой `node test_web.js`; для основного скрипта Node.js не нужен.

**Ограничения:** это простые правила, а не универсальное понимание текста; неоднозначные обращения могут требовать ручной проверки. Черновики не регистрируют заявки, не отправляют сообщения и не утверждают непроверенные адреса или сроки.
