# Классификатор обращений — Prompt & Pray

Скрипт читает обращения из `messages.txt`, определяет категорию (**справка / жалоба / другое**) и печатает черновик ответа на русском. Веб-интерфейс доступен в `index.html`.

## Как запустить

```bash
python3 classify.py          # вывод в терминал
python3 -m unittest test_classifier.py   # тесты
```

Открыть сайт — просто дважды кликнуть на `index.html`.

Зависимостей нет, нужен Python 3.

## Результаты

| Обращение | Категория |
|-----------|-----------|
| Как получить справку о месте учёбы? | справка |
| В столовой очередь, еда холодная. | жалоба |
| Хочу записаться на консультацию завтра. | другое |
| Пропал Wi‑Fi в корпусе B. | жалоба |
| Где парковка для гостей? | другое |

Классификация по ключевым словам, черновик ответа подбирается под тему.
